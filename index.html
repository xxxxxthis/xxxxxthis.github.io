FAQ

자주 묻는 질문

가입부터 Minecraft 접속까지 자주 묻는 내용을 정리했습니다.

PEPE RESTAURANT는 어떤 서버인가요?

게임, 대화와 커뮤니티 활동을 중심으로 운영되는 PEPE 전용 서버입니다. PEPE MANAGER, 인증 시스템, 홈페이지와 관리자 도구 등 운영에 필요한 시스템도 직접 제작하고 있습니다.

Discord 초대 링크는 어디서 받을 수 있나요?

초대 링크는 공개하지 않습니다. 홈페이지의 Discord 초대 요청 페이지에서 Discord 계정으로 요청을 제출하면 운영진이 확인해 승인 또는 거절합니다. 승인된 계정에만 초대 링크가 표시됩니다.

Minecraft 서버 주소는 어떻게 확인하나요?

Minecraft 인증 역할을 가진 유저 또는 Discord 초대 요청이 승인된 유저는 홈페이지 Minecraft 영역에서 승인 상태를 확인한 뒤 Java/Bedrock 접속 주소를 볼 수 있습니다.

초대 요청이 승인됐는데 서버 주소를 볼 때 다시 인증해야 하나요?

같은 브라우저에서는 승인 정보가 일정 시간 유지되므로 보통 다시 인증할 필요가 없습니다. 쿠키나 사이트 저장 데이터를 삭제했거나 인증 정보가 만료된 경우에는 다시 Discord 계정 확인이 필요할 수 있습니다.

Java와 Bedrock 둘 다 접속할 수 있나요?

네. PEPE Minecraft는 Java + Bedrock Crossplay를 지원합니다. 승인된 멤버에게 각 에디션의 접속 정보를 홈페이지에서 제공합니다.

Minecraft 인증 역할은 어떻게 받나요?

Discord의 Minecraft 인증 시스템에서 인증 요청을 제출하고 운영진 승인을 받으면 ✅ MINECRAFT 인증 역할이 지급됩니다. 이후 Java 또는 Bedrock 닉네임을 등록해 계정을 연결할 수 있습니다.

인증 요청이나 초대 요청이 거절되면 어떻게 하나요?

거절 사유가 해결된 뒤 다시 요청할 수 있습니다. 반복적인 허위 요청이나 서버 규칙을 위반하는 요청은 제한될 수 있습니다.

PEPE MANAGER와 꼬붕봇은 어떤 봇인가요?

PEPE MANAGER는 서버 운영, 인증, 활동, 티켓과 자동화를 담당하는 자체 제작 관리 봇이고, 꼬붕봇은 커뮤니티 편의 기능을 담당하는 PEPE 전용 봇입니다.

문의나 신고는 어디서 하나요?

Discord의 티켓 시스템을 이용해 문의·신고·지원 요청을 접수할 수 있습니다. 공개 채널에서 다루기 어려운 내용은 티켓을 이용해주세요.

홈페이지 공지와 Discord 공지는 같은 내용인가요?

홈페이지의 공지·업데이트·Minecraft 소식은 PEPE MANAGER와 연동되어 Discord 공지 채널에도 분류별 임베드 형태로 자동 게시됩니다.
