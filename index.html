FAQ

자주 묻는 질문

Discord 4.0부터 Minecraft 접속·승인 시스템까지 현재 운영 기준으로 정리했습니다.

PEPE RESTAURANT는 어떤 서버인가요?

게임, 대화와 커뮤니티 활동을 중심으로 운영되는 PEPE 전용 커뮤니티입니다. PEPE MANAGER, Discord ↔ Minecraft 인증, 홈페이지, LIVE 상태 연동과 운영 자동화 등 필요한 시스템도 직접 제작·운영하고 있습니다.

Discord 4.0에서는 채널이 어떻게 나뉘나요?

현재 Discord는 ENTRANCE, COMMUNITY, MINECRAFT, VOICE, PEPE SYSTEMS, STAFF의 6개 영역으로 운영됩니다. 입장·공지·문의는 ENTRANCE, 일반 대화와 게임모집은 COMMUNITY, Minecraft 인증과 서버 현황은 MINECRAFT에서 확인할 수 있습니다.

Discord 초대 링크는 어디서 받을 수 있나요?

초대 링크는 공개하지 않습니다. 홈페이지의 Discord 초대 요청 페이지에서 Discord 계정으로 요청을 제출하면 운영진이 승인 또는 거절하며, 승인된 계정에만 초대 링크가 표시됩니다.

문의나 신고는 어디서 하나요?

Discord의 ENTRANCE → 🆘・문의에서 티켓을 생성할 수 있습니다. 생성된 티켓은 운영진 전용 영역에서 처리되며, 공개 채널에서 다루기 어려운 문의·신고·지원 요청에 이용하면 됩니다.

Minecraft 서버 주소는 어떻게 확인하나요?

Minecraft 인증 역할을 가진 유저 또는 Discord 초대 요청이 승인된 유저는 Minecraft 전용 페이지에서 승인 상태를 확인한 뒤 Java/Bedrock 접속 주소를 볼 수 있습니다. 실제 주소는 공개 페이지에 직접 노출되지 않습니다.

Java와 Bedrock 둘 다 접속할 수 있나요?

네. PEPE Minecraft는 Java + Bedrock Crossplay를 지원합니다. 승인된 멤버에게 각 에디션의 접속 정보를 Minecraft 전용 페이지에서 제공합니다.

Minecraft 인증 역할은 어떻게 받나요?

Discord의 MINECRAFT → ⛏️・마크인증에서 인증 요청을 제출하고 운영진 승인을 받으면 ✅ MINECRAFT 인증 역할이 지급됩니다. 이후 Java 또는 Bedrock Minecraft 계정을 등록해 Discord 계정과 연결할 수 있습니다.

초대 요청이 승인됐는데 서버 주소를 볼 때 다시 인증해야 하나요?

같은 브라우저에서는 승인 정보가 일정 시간 유지되므로 보통 다시 인증할 필요가 없습니다. 브라우저의 쿠키·사이트 데이터를 삭제했거나 인증 정보가 만료된 경우에는 Discord 계정 확인이 다시 필요할 수 있습니다.

인증 요청이나 초대 요청이 거절되면 어떻게 하나요?

거절 사유가 해결된 뒤 다시 요청할 수 있습니다. 반복적인 허위 요청이나 서버 규칙을 위반하는 요청은 제한될 수 있습니다.

랭킹·업적·투표·패치노트는 어디서 확인하나요?

Discord 4.0에서는 관련 기능을 PEPE SYSTEMS에 모아두었습니다. 📊・랭킹, 🏅・업적, 🗳️・투표, 📰・패치노트에서 각각 확인할 수 있습니다.

PEPE MANAGER와 꼬붕봇은 어떤 봇인가요?

PEPE MANAGER는 서버 운영, 인증, 티켓, 역할, Minecraft 연동, 공지 연동과 자동화를 담당하는 자체 제작 관리 봇입니다. 꼬붕봇은 커뮤니티에서 사용하는 편의 기능을 제공하는 PEPE 전용 봇입니다.

홈페이지 공지와 Discord 공지는 같은 내용인가요?

홈페이지의 공지·업데이트·Minecraft 소식은 PEPE MANAGER가 감지해 Discord의 📢・공지에도 타입별 Embed 형태로 자동 게시합니다. 이미 연동된 공지는 중복 게시하지 않도록 관리됩니다.
